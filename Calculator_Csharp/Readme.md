# C# Windows Forms Calculator

A simple, desktop-based GUI Calculator built with **C#** and **Windows Forms** using **Visual Studio Code**. This project features a dynamically generated user interface laid out via grid-mapping coordinates directly in code, rendering external designer dependencies unnecessary.

## 🚀 Getting Started

### Prerequisites
* [.NET SDK 8.0+](https://dotnet.microsoft.com/)
* [Visual Studio Code](https://code.visualstudio.com/)
* [C# Dev Kit Extension](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit) for VS Code

### Installation & Execution
1. Clone or download this project directory.
2. Open the project folder in VS Code.
3. Open the integrated terminal (`Ctrl + ~`).
4. Build and execute the application:
   ```bash
   dotnet run
   ```

## 📂 Project Architecture

```text
Calculator/
│
├── Program.cs          # Application entry point; initializes and runs Form1
├── Form1.cs            # Core execution logic, event handlers, and manual UI engine
├── Form1.Designer.cs   # Default autogenerated designer file (left completely untouched)
└── Calculator.csproj   # Project configuration and target framework definitions
```

## 🛠️ Code Implementation Detail

The calculator bypasses drag-and-drop designer components by programmatically injecting form elements via an array layout matrix mapping:

```csharp
string[,] buttons = {
    { "7", "8", "9", "/" },
    { "4", "5", "6", "*" },
    { "1", "2", "3", "-" },
    { "C", "0", "=", "+" }
};
```

### Key Technical Patterns Covered:
* **Partial Classes:** Seamless compilation spanning separate structural logic files.
* **Dynamic Event Binding:** Runtime routing of button click delegate references (`+= ButtonDigit_Click`).
* **State Management:** Tracking continuous calculations across mathematical sequential inputs.
