# Calculator (C++)

A simple command-line calculator developed in **C++**. This project performs basic arithmetic operations through a terminal interface and serves as a beginner-friendly example of C++ programming.

## ✨ Features

* Command-line interface (CLI)
* Basic arithmetic operations

  * Addition
  * Subtraction
  * Multiplication
  * Division
* Simple and lightweight
* Easy to understand and modify

## 🛠️ Technologies Used

* C++
* CMake
* GCC / MinGW / MSVC
* Visual Studio Code (or any C++ IDE)

## 📂 Project Structure

```text
Calculator/
├── CMakeLists.txt
├── main.cpp
├── build/
└── README.md
```

## 🚀 Getting Started

### Prerequisites

* C++ Compiler (GCC, MinGW, MSVC, or Clang)
* CMake 3.16 or later

### Clone the Repository

```bash
git clone https://github.com/<your-username>/Calculator.git
```

### Build the Project

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

### Run the Application

**Windows**

```bash
.\Calculator.exe
```

**Linux/macOS**

```bash
./Calculator
```
